هاد المجلد (اسمه SITE) فيه موقعك كامل وجاهز للرفع. محتوياته:

   • index.html          ← الموقع نفسه (ملف واحد، كل الكود جوّاه)
   • content.json        ← ملف تعديلاتك (يبدأ فاضي، يتحدّث من صفحة الأدمن)
   • .nojekyll           ← ملف ضروري لـ GitHub (لا تحذفه، لا تفتحه)
   • assets/             ← مجلد صورك وفيديوهاتك و PDF

ملاحظة مهمة: صفحة الأدمن مدمجة جوّا index.html — ما في ملف أدمن منفصل.


──────────────────────────────────────────────────────────────────
  أولاً: كيف ترفع الموقع على GitHub (أول مرة فقط)
──────────────────────────────────────────────────────────────────

الطريقة الموصى بها — موقع على اسمك مباشرة (بدون مجلد فرعي):

  1. سجّل دخول على github.com
  2. اضغط "New repository" (مستودع جديد)
  3. سمّي المستودع بالضبط هيك:   USERNAME.github.io
     (بدّل USERNAME باسم حسابك على GitHub. مثال: yazan.github.io)
  4. خلّيه Public، واضغط "Create repository"
  5. اضغط "uploading an existing file"
  6. اسحب كل محتويات مجلد SITE (index.html و content.json
     و .nojekyll ومجلد assets كامل) وأفلتها هناك
  7. اضغط "Commit changes"
  8. انتظر دقيقة، وافتح:   https://USERNAME.github.io
     ← موقعك صار أونلاين ✓

(لو ما ظهر ملف .nojekyll وقت السحب: هو مخفي. فعّل إظهار الملفات
 المخفية على جهازك، أو تجاهله — الموقع بيشتغل غالباً بدونه.)


──────────────────────────────────────────────────────────────────
  ثانياً: كيف تعدّل الموقع (صفحة الأدمن)
──────────────────────────────────────────────────────────────────

  1. افتح موقعك وأضف #admin في آخر الرابط:
        https://USERNAME.github.io/#admin
  2. كلمة السر:   Yazan@2026!
        (لتغييرها: عدّل السطر PASSWORD داخل src/admin/Admin.tsx
         ثم أعد بناء الموقع — راجع "للمطوّر" بالأسفل)
  3. عدّل أي شي من التبويبات على اليسار:
        • Contact & Links : الإيميل، واتساب، السوشيال، الموقع
        • Logo            : تبديل اللوغو (3 نسخ)
        • Hero Video      : فيديو الخلفية بالأعلى
        • Hero Text       : عنوان وكلام أول الصفحة (عربي + إنجليزي)
        • Photography     : صور المعرض — صارت مرتّبة بمجلدات
                            (اقرأ قسم "خامساً" بالأسفل)
        • Videos          : الفيديوهات
        • Social / Clients: العملاء والتصاميم
        • Client Logos    : شعارات العملاء
        • Ad Campaigns    : الحملات والأرقام
        • About Text      : نبذة "عني" (عربي + إنجليزي)
        • Publish         : يرفع الصور والتعديلات على GitHub مباشرة
                            (اقرأ قسم "سابعاً")
  4. اضغط "Save & preview" ← تشوف تعديلك مباشرة على الموقع (عندك أنت)
  5. لما تخلّص، اضغط "Download content.json"
        ← بينزّل ملف اسمه content.json


──────────────────────────────────────────────────────────────────
  ثالثاً: كيف تنشر تعديلاتك للناس (كل مرة تعدّل)
──────────────────────────────────────────────────────────────────

  1. من صفحة الأدمن: عدّل → Download content.json
  2. روح على مستودعك في GitHub
  3. اضغط على ملف content.json القديم → اضغط أيقونة سلة المهملات
     (Delete) → Commit.  (أو مباشرة: Add file ← Upload files
     وارفع الجديد فوق القديم — بيستبدله)
  4. ارفع ملف content.json الجديد اللي نزّلته
  5. انتظر دقيقة → حدّث موقعك ← تعديلاتك ظهرت للكل ✓

الخلاصة: النصوص والكلام تتغيّر بملف content.json بس. ما بتحتاج
تلمس index.html أبداً بعد أول رفعة.


──────────────────────────────────────────────────────────────────
  رابعاً: كيف تضيف/تبدّل صور وفيديوهات
──────────────────────────────────────────────────────────────────

الصور والفيديو الكبيرة تنحطّ بمجلد assets (مش داخل content.json،
عشان يبقى خفيف وسريع).

  • مجلد الصور:    assets/photography/   و  assets/clients/  ...الخ
  • مجلد الفيديو:  assets/hero/
  • مجلد اللوغو:   assets/brand/
  • ملفات PDF:     assets/  (السيرة والبورتفوليو)

طريقة إضافة صورة جديدة:
  1. ارفع الصورة داخل مجلد assets المناسب على GitHub
     (مثلاً: assets/photography/cars/new.jpg)
  2. من صفحة الأدمن، بتبويب Photography، ضع المسار:
     /assets/photography/cars/new.jpg
  3. Download content.json ← ارفعه ← ظهرت الصورة ✓

بالنسبة للفيديو: ارفع الملف بمجلد assets/hero/ ثم ضع مساره
بتبويب Hero Video. (الفيديو الافتراضي اسمه reel.mp4 — استبدله
بنفس الاسم وبيشتغل مباشرة بدون أي تعديل ثاني).

صور اللوغو الصغيرة تقدر ترفعها مباشرة من زر "Upload from device"
داخل تبويب Logo (بتنحفظ جوّا content.json مباشرة).


──────────────────────────────────────────────────────────────────
  خامساً: مجلدات الصور (الجديد) — كل عميل بمجلد فيه لوغو
──────────────────────────────────────────────────────────────────

صار قسم التصوير مرتّب هيك:

     القسم (مطاعم / سيارات / طبي / عقارات / منتجات)
        └── مجلد لكل عميل  ← عليه لوغو العميل واسمه
              └── صور العميل

يعني بقسم "مطاعم" رح تشوف مربعات، كل مربع عليه لوغو مطعم واسمه
(مثلاً: مطعم فراس). لما الزائر يضغط عليه، بتفتح صور هالمطعم لحالها.
ونفس الشي بباقي الأقسام.

قسم السيارات فيه مستوى زيادة:

     سيارات
        └── معرض فيلوسيتي موتورز        ← اسم المعرض + لوغو المعرض
              ├── سيارات رياضية          ← نوع السيارة
              ├── سيارات فخمة
              └── سيارات كلاسيكية
                    └── الصور

كيف تضيف/تعدّل من صفحة الأدمن:

  1. افتح #admin → تبويب Photography
  2. اختار القسم من الأزرار فوق (مطاعم، سيارات... الخ)
  3. اضغط "Add folder" لتضيف عميل / معرض جديد
  4. جوّا المجلد عبّي:
        • Folder / client name (EN)  ← الاسم بالإنجليزي
        • (AR) اسم العميل            ← الاسم بالعربي
        • Logo                        ← لوغو العميل (PNG شفاف أفضل)
                                        إذا تركته فاضي بيظهر الاسم مكانه
        • Cover                       ← خلفية اختيارية خلف اللوغو
                                        (إذا فاضية بياخد أول صورة تلقائياً)
        • Photos                      ← صور المجلد ("Add photo")
  5. للسيارات: جوّا مجلد المعرض في قسم اسمه Sub-folders —
     اضغط "Add sub-folder" وسمّيه بنوع السيارة، وحط صوره جوّاه.
     (الـ Sub-folders متاحة بكل الأقسام مش بس السيارات، استعملها إذا لزم)
  6. اضغط السهم جنب اسم المجلد لتطويه أو تفتحه.
  7. Save & preview ← Download content.json ← ارفعه على GitHub

ملاحظات:
  • اللوغوهات صغيرة الحجم فارفعها مباشرة بزر "Upload from device"
    (بتنحفظ جوّا content.json).
  • الصور الكبيرة الأفضل ترفعها بمجلد assets وتحط مسارها، مثلاً:
    /assets/photography/restaurants/firas/01.jpg
  • إذا عندك content.json قديم (قبل التحديث)، الموقع رح يقرأه عادي
    وبيحوّل صور كل قسم لمجلد واحد تلقائياً — بعدها رتّبها متل ما بدك.


──────────────────────────────────────────────────────────────────
  سادساً: الطريقة السريعة — زر "Import a folder"
──────────────────────────────────────────────────────────────────

بدل ما تضيف كل مجلد وكل صورة بالإيد، رتّب صورك على جهازك مرة وحدة
واستوردها كلها بضغطة.

الخطوة ١ — رتّب المجلد على جهازك:

     restaurants/
        firas/
           logo.png        ← اللوغو (اسمه لازم يكون logo بالضبط)
           cover.jpg       ← خلفية اختيارية (اسمها cover)
           01.jpg
           02.jpg
        aroma-cafe/
           logo.png
           01.jpg

  وللسيارات:

     cars/
        velocity-motors/          ← اسم المعرض
           logo.png
           sports/                ← نوع السيارة
              01.jpg
           luxury/
              01.jpg

  (أسماء المجلدات والملفات إنجليزي وبدون مسافات — استعمل - بدل المسافة)

الخطوة ٢ — استورد:

  1. افتح #admin ← تبويب Photography
  2. اختار القسم من فوق (مثلاً Restaurants)
  3. اضغط "Import a whole category folder" واختار مجلد restaurants
     (أو "Import one client folder" إذا بدك تستورد عميل واحد بس)
  4. الموقع بيبنيلك: مجلد لكل عميل، اللوغو من ملف logo.png، الصور
     مرتّبة بالأرقام، والمسارات جاهزة — بدون ما تكتب ولا مسار
  5. بيسألك: تستبدل الموجود ولا تضيف جنبه — اختار اللي بدك ياه
  6. عدّل الأسماء العربية بس (الإنجليزي بيتعبّى من اسم المجلد)

الخطوة ٣ — ارفع نفس المجلد على GitHub:

  • إذا استوردت "category folder"  ← ارفع المجلد جوّا:  assets/photography/
  • إذا استوردت "client folder"    ← ارفع المجلد جوّا:  assets/photography/<القسم>/

  يعني بتسحب نفس المجلد اللي اخترته بالضبط وبتفلته هناك. خلص.

الخطوة ٤ — Save & preview ← Download content.json ← ارفعه ← ✓


بدك تتجنّب GitHub نهائياً؟
  فعّل خيار "Embed the photos inside content.json" قبل الاستيراد.
  وقتها الصور بتنحفظ جوّا content.json مباشرة (بتنضغط تلقائياً لعرض
  1600 بكسل). مناسب لعشرات الصور، بس خلّي حجم الملف أقل من ١٠ ميغا
  وإلا الموقع بيبطّئ. للأعداد الكبيرة استعمل طريقة assets.

زر إضافي: "Add many photos"
  جوّا أي مجلد في زر بيسمحلك تختار صور كتير مرة وحدة. إذا خانة المسار
  (Photos path) معبّاية بياخد أسماء الملفات ويركّب المسارات لحاله،
  وإذا فاضية بيضمّن الصور جوّا content.json.


──────────────────────────────────────────────────────────────────
  سابعاً: النشر المباشر — تبويب Publish (بدون ما تنقل ولا ملف)
──────────────────────────────────────────────────────────────────

هاد التبويب بيرفع الصور و content.json من صفحة الأدمن لمستودعك على
GitHub مباشرة. يعني بتختار مجلد صورك من جهازك، وبضغطة وحدة بيصير كل
شي أونلاين. ما في نقل ولا سحب ملفات ولا شي.

خطوة لمرة وحدة — اعمل توكن (مفتاح دخول):

  1. GitHub ← صورتك فوق يمين ← Settings
  2. تحت لتحت: Developer settings
  3. Personal access tokens ← Fine-grained tokens
  4. Generate new token
  5. Repository access ← Only select repositories ← اختار مستودع موقعك
  6. Permissions ← Repository permissions ← Contents ← اختار:
        Read and write
  7. حط تاريخ انتهاء (مثلاً سنة) ← Generate
  8. انسخ التوكن (بيظهرلك مرة وحدة بس!)

الإعداد بالأدمن:

  1. افتح #admin ← تبويب Publish
  2. عبّي:
        • GitHub username   ← اسم حسابك
        • Repository name   ← اسم المستودع (مثلاً yazan.github.io)
        • Branch            ← غالباً main
        • Folder inside repo← اتركها فاضية
        • Token             ← الصق التوكن
  3. اضغط "Test connection"
        ✓ أخضر ← تمام
        ✗ أحمر ← بيقلّك وين الغلط بالضبط (توكن، فرع، صلاحية)
  4. إذا بدك يتذكّر التوكن على جهازك، فعّل الخيار تحته.
     إذا ما فعّلته بينمسح لما تسكّر التبويب.

الاستعمال اليومي:

  1. تبويب Photography ← "Import a whole category folder" ← اختار مجلدك
  2. عدّل الأسماء العربية إذا بدك
  3. تبويب Publish ← اضغط "Publish to GitHub"
  4. بيطلعلك تقدّم: Uploading 12/40…
  5. لما يخلص بيطلع سطر أخضر فيه رقم الـ commit
  6. انتظر دقيقة (GitHub Pages بيعيد البناء) ← حدّث موقعك ← ✓

كل شي بينرفع بـ commit واحد — مو ٤٠ commit لأربعين صورة.

تحذير مهم بخصوص التوكن:

  • التوكن متل كلمة سر مستودعك. لا تحطه بأي مكان عام، ولا تبعته لحدا،
    ولا تحطه بملف وترفعه.
  • التوكن بينحفظ على متصفحك إنت فقط. ما بينكتب أبداً جوّا content.json
    ولا جوّا ملف الموقع. وفي زر "Forget token" بيمسحه.
  • إذا حسّيت إنه انكشف: من GitHub احذف التوكن (Revoke) واعمل غيره.

ملاحظات:

    الرفع عشان المستودع يضل خفيف والموقع سريع. خلّيه مفعّل.
  • الصور اللي استوردتها بتضل بذاكرة المتصفح لحتى ترفعها. إذا عملت

    (الموقع بينبّهك قبل ما تسكّر الصفحة)
  • بيظهرلك عدّاد فوق بالأدمن فيه عدد الصور المنتظرة الرفع.
  • إذا ما بدك تستعمل التوكن نهائياً: الطريقة اليدوية القديمة لسا شغالة
    (Download content.json وارفعه بالإيد).
