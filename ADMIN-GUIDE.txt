YAZAN Portfolio — Admin Guide
=============================

Open the admin panel:  <your-site-url>/#admin   (or open the site and add #admin)
Password:  yazan   (change it in src/admin/Admin.tsx → PASSWORD)

Tabs:
- Contact & Links : email, WhatsApp, socials, Résumé URL, Portfolio URL, location.
- Hero Video      : the top full-screen video.
- Photography     : photo galleries, organised in FOLDERS (see below).
- Videos          : video items.
- Social/Clients  : social stats + client names.
- Client Logos    : client logo grid.
- Ad Campaigns    : campaign image, title (EN/AR) AND the numbers on each card.
                    Each "number" has a Label (EN/AR) and a Value (e.g. 0, 3.1M, 4.7%).
                    Add / remove numbers per campaign with "Add number" / trash icon.
- About Text      : your bio (EN/AR).

Photography folders
-------------------
Each category (Restaurants / Cars / Medical / Real Estate / Products) holds one
folder per client. A folder has:
  * Name (EN + AR)  - shown under the tile
  * Logo            - the client's logo, shown on the folder tile
                      (transparent PNG works best; if empty the name is shown)
  * Cover           - optional background photo behind the logo
                      (defaults to the folder's first photo)
  * Photos          - what opens when a visitor clicks the folder

Cars work one level deeper: the folder is the SHOWROOM name, and inside it you
add a sub-folder per CAR TYPE (Sports / Luxury / Classic ...), each with its own
photos. Sub-folders are available in every category if you need them.

Downloads on the site:
- "Download résumé"    → Résumé URL   (default /assets/YAZAN-Resume.pdf)
- "Download portfolio" → Portfolio URL (default /assets/YAZAN-Portfolio.pdf)
  To change either file, replace the PDF in public/assets/ (keep the same name)
  OR paste a new URL in the Contact & Links tab.

Email row: clicking it now opens the visitor's mail app (mailto). The "Copy email"
button still copies the address.

Saving changes:
1. Edit in the panel → "Save & preview" (saves to this browser, previews live).
2. Click "Export" to download an updated portfolio.ts.
3. Replace src/data/portfolio.ts with it and rebuild/redeploy for everyone.
